# Padel Hub — інтернет-магазин

Повноцінний сайт-магазин на Next.js: каталог товарів з анімаціями, кошик,
оформлення замовлення, оплата на сайті (Stripe / LiqPay / оплата при
отриманні), сповіщення про замовлення на пошту та панель адміністратора
для редагування товарів, фото, налаштувань пошти й оплати.

## Що є в комплекті

- **Вітрина**: анімована головна сторінка, картки товарів, сторінка товару
  з галереєю до 5 фото, кошик, оформлення замовлення з пошуком міст/відділень
  Нової пошти.
- **Оплата на сайті**: готова інтеграція Stripe та LiqPay (потрібно лише
  вставити ваші ключі в адмінці) + оплата при отриманні як запасний варіант.
- **Пошта**: після кожного замовлення на вказану адресу (за замовчуванням
  `Padelhub50@gmail.com`) надсилається лист з повною інформацією про
  замовлення, товари, клієнта та доставку.
- **Панель адміністратора** (`/admin`, пароль за замовчуванням `padelhub2026`):
  - Товари — додавання/редагування назви, ціни, опису, категорії, залишку,
    до 5 фотографій на товар.
  - Замовлення — перегляд усіх замовлень та зміна статусу.
  - Налаштування — контент сайту (заголовки, контакти, соцмережі), дані
    поштової скриньки (SMTP), ключі Stripe/LiqPay, ключ API Нової пошти,
    зміна пароля адміністратора.

## Швидкий старт (локально)

```bash
npm install
cp .env.example .env       # заповніть ADMIN_SESSION_SECRET
npm run dev
```

Сайт: http://localhost:3000
Адмінка: http://localhost:3000/admin (пароль `padelhub2026`, змінюється в
Налаштування → Безпека одразу після першого входу).

Щоб наповнити каталог стартовими товарами (без фото — фото додаєте самі
в адмінці):

```bash
npm run seed
```

## Дуже важливо про розгортання (деплой)

Цей сайт зберігає товари, замовлення та налаштування у файлі бази даних
SQLite (`data/padelhub.db`) прямо на диску сервера. Це означає, що хостинг
має надавати **постійний (persistent) диск**, який не стирається між
запитами.

✅ **Підходить**: Render (Web Service, не Static Site), Railway, Fly.io,
DigitalOcean App Platform, звичайний VPS (з PM2/systemd).

❌ **НЕ підходить**: Vercel / Netlify у режимі serverless-функцій — там
файлова система тимчасова і всі зміни (нові товари, замовлення) зникнуть
після наступного запиту. Якщо хочете лишитися на Vercel — потрібно
підключити окрему хмарну базу даних (Postgres/Turso) замість SQLite;
для цього доведеться замінити `lib/db.js`.

### Приклад деплою на Render

1. Створіть Web Service з цього репозиторію.
2. Build Command: `npm install && npm run build`
3. Start Command: `npm start`
4. Додайте Persistent Disk (наприклад, 1GB, змонтований у `/app/data`) і
   встановіть змінну середовища `DATABASE_DIR=/app/data`.
5. Додайте змінні середовища з `.env.example` (`ADMIN_PASSWORD`,
   `ADMIN_SESSION_SECRET`).

### Приклад деплою на VPS

```bash
git clone <your-repo>
cd padelhub
npm install
npm run build
cp .env.example .env   # відредагуйте
npm start               # або через pm2: pm2 start npm --name padelhub -- start
```

Поставте Nginx/Caddy як реверс-проксі з HTTPS перед портом 3000.

## Підключення оплати

Зайдіть в **Керування → Налаштування → Оплата**.

### Stripe (міжнародні картки, Apple/Google Pay)

1. Зареєструйтесь на https://dashboard.stripe.com
2. Developers → API keys → скопіюйте **Publishable key** та **Secret key**.
3. Вставте їх в адмінці, увімкніть перемикач Stripe.
4. Developers → Webhooks → Add endpoint → URL: `https://ваш-сайт/api/webhooks/stripe`,
   подія `checkout.session.completed`. Скопіюйте **Signing secret** і теж
   вставте в адмінці.

### LiqPay (українські картки, ПриватБанк)

1. Зареєструйтесь на https://www.liqpay.ua
2. Кабінет → Мій магазин → Налаштування API → скопіюйте **Public key** та
   **Private key**.
3. Вставте їх в адмінці, увімкніть перемикач LiqPay.
4. Сервер сам передає LiqPay адресу для callback (`/api/webhooks/liqpay`) —
   нічого додатково вказувати в кабінеті LiqPay не потрібно.

Якщо жодна з систем ще не підключена — на сайті автоматично залишається
доступною **оплата при отриманні**, тож магазин працює одразу.

## Підключення пошти (сповіщення про замовлення)

Керування → Налаштування → Пошта.

Найпростіший варіант — Gmail:

1. Увімкніть двофакторну автентифікацію на акаунті, з якого надсилатимете
   листи (не обов'язково `Padelhub50@gmail.com` — можна створити окрему
   поштову скриньку спеціально для надсилання).
2. Створіть «пароль додатку»: https://myaccount.google.com/apppasswords
3. В адмінці вкажіть: хост `smtp.gmail.com`, порт `465`, SSL увімкнено,
   логін — повна адреса скриньки, пароль — щойно створений пароль додатку.
4. У полі «Кому надсилати замовлення» вкажіть `Padelhub50@gmail.com`.
5. Увімкніть перемикач «Увімкнути надсилання листів» і натисніть
   «Надіслати тест», щоб перевірити.

Підійде будь-який інший поштовий сервіс з підтримкою SMTP (Outlook, Zoho,
SendGrid, Resend тощо) — просто вкажіть відповідні хост/порт/логін/пароль.

## Нова пошта (пошук міст і відділень)

Керування → Налаштування → Доставка → вставте ваш API-ключ Нової пошти
(особистий кабінет НП → Налаштування → API). Без ключа форма замовлення
просто показує звичайні текстові поля «Місто» / «Відділення» — сайт працює
в будь-якому разі.

## Технології

Next.js 14 (App Router) · React 18 · Tailwind CSS · Framer Motion ·
better-sqlite3 · nodemailer · stripe · lucide-react.

## Структура проєкту

```
app/                 сторінки та API-роути (App Router)
  admin/             панель адміністратора (захищена)
  api/                серверні маршрути (товари, замовлення, оплата, пошта)
components/          React-компоненти вітрини й адмінки
context/             CartContext (кошик, localStorage)
lib/                 доступ до БД, авторизація, пошта, оплата, Нова пошта
scripts/seed.mjs     наповнення каталогу стартовими товарами
data/                файл бази даних SQLite (створюється автоматично)
```
